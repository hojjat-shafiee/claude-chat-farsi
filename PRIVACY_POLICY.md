# Privacy Policy for Claude Farsi Fonts & RTL

**Last Updated:** October 13, 2026

## 1. Overview
**Claude Farsi Fonts & RTL** is a browser extension designed to enhance Persian and Arabic typography and bidirectional text flow on `claude.ai`. We respect your privacy and are committed to protecting it.

## 2. Data Collection and Usage
- **No Personal Data Collected:** The extension does **NOT** collect, track, log, or monitor any personal information, chat messages, browsing history, or user identity.
- **No Remote Transmission:** The extension does not transmit any information to third-party servers, analytics services, or external APIs.
- **Local Settings Storage:** The extension only saves user customization preferences (such as selected font family, font size, line height, font weight, and RTL toggles) using `chrome.storage.sync` or `chrome.storage.local`. This data is stored strictly within your browser profile to preserve your UI settings across sessions.

## 3. Permissions Justification
- `storage`: Required solely to save and retrieve your custom typography preferences locally within the browser.
- `host_permissions` (`https://claude.ai/*`, `https://*.claude.ai/*`): Required exclusively to apply custom open fonts and right-to-left layout adjustments to chat messages and prompts on `claude.ai`.

## 4. Third-Party Services
This extension does not use any third-party tracking, analytics, advertising networks, or external CDN services. All font files (Vazirmatn, Estedad, Shabnam, Sahel) are bundled directly inside the extension package for security, performance, and offline availability.

## 5. Contact
If you have any questions or feedback regarding this Privacy Policy, please open an issue on our GitHub repository or contact the developer.
