**Short Description** [REQUIRED]

**Detailed Description** [REQUIRED]
Enhance your conversation experience in Claude AI with beautiful open Persian fonts and natural right-to-left alignment.

Claude Farsi Fonts & RTL upgrades the typography on claude.ai by applying popular, high-legibility open-source Persian and Arabic typefaces directly to chat messages and prompts.

Key Features:
- Four curated open-source Persian fonts: Vazirmatn (default), Estedad, Shabnam, and Sahel.
- Support for custom local fonts (such as IRANSans, Dana, Peyda, or any installed font).
- Intelligent automatic RTL (Right-to-Left) detection for Persian and Arabic paragraphs.
- Typing assistance: Automatically adapts the message input box to RTL when typing Persian.
- Typography tuning: Customizable font size (13px to 22px), line height, and font weight (light to bold).
- Persian numerals toggle: Switch between Persian digits (۰-۹) and standard numerals.
- Code block preservation: Code snippets and monospace blocks always stay in English LTR with standard developer fonts.
- Bilingual popup interface with instant live preview.

How to Use:
1. Open claude.ai in your browser.
2. Click the extension icon in your browser toolbar to open settings.
3. Select your favorite Persian font (Vazirmatn, Estedad, etc.) and adjust size or line-height.
4. Your preferences apply instantly without refreshing the page.

Privacy Note:
This extension runs entirely in your browser. It does not track, collect, transmit, or store any personal data or chat messages. All typography settings are stored locally in your browser sync storage.
